# Вынос базы для нового проекта (ИИ-консультант в Telegram)

Это не рабочий проект, а вырезка общего инженерного каркаса из HF Nha Trang —
той части, которая не про еду/подписки, а про "Telegram + Claude + админка"
как таковые. Дальше переносится в отдельный репозиторий под новый проект.

## Структура

- `PLAN.md` — план нового проекта: что за продукт, что берём готовым, что
  строим с нуля, открытые вопросы (не решены мной — решает заказчик/Игорь).
- `agent-bot-base/` — копия `agent-bot`, оставлены только файлы общего
  движка (вебхук, оркестратор, вызов Claude, красная зона, антидребезг
  сообщений, идемпотентность). HF-специфичная бизнес-логика (заказы,
  подписки, тарифы, Sheets-импорт, уровни ккал) НЕ копировалась — в
  `orchestrator.py`/`main.py` она осталась как есть (это те же файлы из HF),
  под новый продукт их нужно будет вычистить точечно, см. `PLAN.md`.
- `admin-panel-base/` — копия `admin-panel`, оставлены страницы/компоненты
  общего назначения: диалоги, эскалации, промпт агента, зелёная/красная
  зона, вход по QR, уведомления сотрудникам, статус сервиса. Экраны про
  тарифы/доставки/клиентов/Sheets НЕ копировались.
- `supabase/schema-base.sql` — та же схема, что в HF
  (`supabase_minimal_schema.sql`), без бизнес-таблиц (clients/subscriptions/
  sheet_import и т.п.), с комментариями `TODO` там, где значения
  HF-специфичны (категории эскалаций, роли сотрудников, красная зона).

## Важно — это черновик-каркас, не готовый продукт

Скопированные файлы всё ещё содержат комментарии/докстринги про HF
(еду, рационы, Ольгу/Франсуа) — они не переписаны и не должны восприниматься
как готовое решение. Смысл выноса — дать реальный работающий код архитектуры
(вебхук, дебаунс, ESCALATE-протокол, dual-API fallback, prompt caching,
human takeover, live-чат в админке) в руки, а не переизобретать это заново.
Что именно нужно вычистить/переписать под новый продукт — см. `PLAN.md`,
раздел "Что менять в скопированных файлах".

Ничего в оригинальных `agent-bot`/`admin-panel` (git-репозитории HF) не
трогал и не удалял — только читал и копировал.
